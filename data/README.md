# 本地数据

服务首次创建饭局时会生成 `food-wheel.json`，包含饭局、成员、成员身份凭证、预算与排除项、结果、餐后反馈、事件记录。

- 文件保存在当前电脑，不上传云端，不通过静态文件接口提供下载。
- 原子写入临时文件后重命名，正常重启服务可以恢复。
- 备份服务器数据时，先停止服务，然后复制整个文件；这是完整服务备份，包含参与凭证，不建议公开分享。
- 店铺收藏夹、昵称和各浏览器的参与凭证保存在各自浏览器 LocalStorage。
- 页面「导出数据」是店铺与决策摘要的可分享 JSON，不包含参与凭证；导入功能只合并店铺，不恢复房间身份。
- 当前目录中的体验饭局由开发验证生成，不代表真实用户或实际经营数据。
